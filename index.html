QViewing

Cue display and notes light for lighting designers.

Connect to your console

  1. On the console: Setup ▸ System ▸ Show Control ▸ OSC — turn on OSC RX and OSC TX. Note the OSC TCP Mode and OSC TCP Server Port.
  2. Put your iPhone on a network that can reach the console.
  3. In QViewing: Settings ▸ enter the console IP, the same port (default 8000) and format (default OSC 1.1 (SLIP)) ▸ Connect.
  4. Allow Local Network access when iOS asks.

White screen notes light

Press and hold anywhere for a white light. Keep holding and slide up or down to change brightness — it is remembered. Release to return to your cues.

Troubleshooting

  • Stuck on “Connecting…” — the phone can't reach the console. Check the IP, the Wi-Fi network, and that the phone is not using a manual IP on the wrong subnet.
  • “Connection refused” — the network is fine, but the port or OSC TCP mode doesn't match the console.
  • Connected but no cues — make sure OSC TX is on and the TCP format matches.
